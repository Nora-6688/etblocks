# ET‑blocks 企业培训系统 ｜ 功能需求清单（原型 & 开发版）

> **文档版本：** v2.0 ｜ 2026-08-25
> **系统定位：** 企业新人培训 + 员工日常培训系统
> **UI 主色调：** 蓝白 + 湖绿色，重点元素橙色高亮；风格：简洁商务 + 科技感
> **权限逻辑：** 学员端、管理端可页面切换，后台权限控制；管理账号可查看两套页面，普通学员仅可见学员端
> **登录方式：** 前期邮箱/手机号账号密码登录，后续对接企业微信免登；测试账号：Nora；右上角展示用户名 + 身份（学员/管理员），旁边有"退出"，退出后跳转登录页

## 一、权限与账号体系

### 1.1 登录与退出

| 编号 | 需求 | 说明 |
|------|------|------|
| 1.1.1 | 账号密码登录 | 支持手机号 / 企业邮箱 + 密码登录 |
| 1.1.2 | 企业微信免登 | 后续扩展（Phase 3），企微环境下 OAuth 自动登录并识别身份 |
| 1.1.3 | 用户名 + 身份展示 | 右上角显示"用户名 · 身份"（学员 / 管理员） |
| 1.1.4 | 退出登录 | 点击"退出"跳转登录页，清除会话状态 |
| 1.1.5 | 测试账号 | Nora（管理员身份），用于前期功能测试 |

### 1.2 角色权限控制

| 角色 | 可访问页面 | 操作权限 |
|------|-----------|----------|
| 学员（普通用户） | 仅【学员端】 | 无管理操作入口 |
| 管理员 | 学员端 + 管理端 | 可切换查看两套页面，拥有全部后台管理权限 |

### 1.3 用户基础信息（学员管理数据源）

**基础字段：**

| 字段 | 说明 |
|------|------|
| 姓名 | 必填 |
| 入职时间 | 日期选择 |
| 所属部门 | 业务部 / 客服部 / 商务部 / 产品部 / 职能部 |
| 岗位 | 下拉选择，与部门联动 |
| 岗位层级 | 新人期 / 成长期 / 专业期 / 资深期 |
| 账号状态 | 开通 / 关闭（关闭后无法登录） |

**账号操作：** 启用 / 禁用账号、密码重置、基础信息编辑、岗位层级字典维护

## 二、学员端（用户端）

> **设计原则：** 工作台为首页，AI 问题诊断模块放在首页最显眼位置。
> **移除项：** 本周学习时长、连续学习统计（不在首页展示）。
> **首页保留 4 块：** 已完成课程、待处理任务、我的学习路径、接下来要做。

### 2.1 工作台（首页）

#### 2.1.1 AI 问题诊断（核心入口）

- **岗位下拉筛选：** 业务岗、客服岗、商务岗、产品岗、职能岗
- **用户输入：** 当前岗位描述 + 工作中遇到的困难（文本输入框）
- **AI 处理：** 调用大模型 API + Prompt，分析用户能力短板，自动生成个性化学习路径
- **AI 输出：** 推荐当前能力短缺分析 + 对应知识点 + 推荐学习课程清单
- **路径同步：** 生成的学习路径自动同步到【我的学习路径】卡片
- **关联能力：** 后续对接考试主观题 AI 批改（考试模块）

#### 2.1.2 首页数据 & 任务卡片（仅 4 块）

| 卡片 | 内容 | 数据来源 |
|------|------|----------|
| 已完成课程 | 已完成课程数量 + 最近完成课程入口 | 学习记录 |
| 待处理任务 | 待学课程 / 待完成试卷数量 + 快速入口 | 待学内容 + 课后训练 |
| 我的学习路径 | AI 诊断生成 / 管理员指派的学习路径 | AI 诊断 + Blocks 指派 |
| 接下来要做 | 待学课程 + 待完成试卷训练汇总，按截止时间排序 | 待学内容 + 课后训练 |

### 2.2 学习列表

> 课程支持两种内容形态：**单个课程** 和 **组合课程 Blocks**（课程包，包含多个课程或测练题）。

#### 2.2.1 顶部工具栏

- 搜索框（课程名称模糊搜索）
- 重置按钮（清空所有筛选条件）
- 刷新按钮

#### 2.2.2 筛选条件

| 筛选项 | 选项 |
|--------|------|
| 岗位 | 业务岗、客服岗、产品岗、商务岗、职能岗 |
| 岗位层级 | 新人期、成长期、专业期、资深期 |
| 课程内容分类 | 规章制度、企业文化、工作流程、行业知识、岗位知识 |

#### 2.2.3 课程展示与交互

- 课程卡片展示：课程封面（分类色彩）+ 课程名称 + 简介 + 标签 + 难度
- 添加待学：点击"+ 待学"将课程添加至【待学内容】
- 课程播放页：
  - 视频类：支持倍速播放（1x / 1.25x / 1.5x / 2x）、上句、下句、全屏
  - 文档 / PPT / PDF 类：在线预览阅读
- 课程格式支持：文档、表格、PPT、PDF、视频

### 2.3 待学内容

#### 2.3.1 内容来源

| 来源 | 说明 |
|------|------|
| 学员手动添加 | 从学习列表点击"+ 待学"添加 |
| 管理员指派 | 指派课程 / Blocks（含多课程 + 测练题），指派后生成待学通知 |

#### 2.3.2 待学通知与提醒

- 指派后学员端收到通知，展示待学习数量提醒（角标）
- 待学任务状态区分：

| 状态 | 展示 |
|------|------|
| 未开始 | 灰色标签 |
| 进行中 | 蓝色/橙色标签 + 学习进度条 + 到期时间 |
| 已超时 | 红色标签 + 超时提醒 |

- 任务完成后自动移出待学列表，归入历史记录

#### 2.3.3 任务类型

- 课程任务（单个课程）
- Blocks 任务（课程包，含多课程 + 测练）
- 训练题任务
- 试卷任务

### 2.4 课后训练

> 练习题、考试试卷、管理员指派试卷统一入口。

#### 2.4.1 分类（4 个标签页）

| 标签 | 内容 |
|------|------|
| 练习题 | 随堂练习、章节测试 |
| 考试试卷 | 含管理员指派试卷 / Blocks 内包含的测练 |
| 指派试卷 | 管理员定向指派的试卷，含截止时间 |
| 错题本 | 学员自主编辑的错题集 |

#### 2.4.2 练习题交互流程

1. 点击"练习"按钮 → 题目下方出现空白答题框
2. 学员作答 → 点击"完成"按钮
3. 自动展示参考答案（对比正误）

#### 2.4.3 考试试卷交互流程

1. 点击试卷 → 展示试卷名称、考试时间、题量、及格分
2. 点击"开始考试" → 进入答题页面
3. 客观题自动判分，主观题等待管理员阅卷（或 AI 辅助批改）
4. 阅卷完成后 → 学员可查看成绩与阅卷结果
5. 学员可自助将错题编辑到错题本

#### 2.4.4 错题本

- 点进去是一个空白编辑区域，可放文字、图片
- 支持分享给其他人（生成分享链接 / 企微内转发）

### 2.5 个人中心（新增）

| 功能 | 说明 |
|------|------|
| 个人基础信息 | 姓名、部门、岗位、入职时间、账号状态 |
| 全部学习记录 | 历史课程列表、历史考试成绩 |
| 我的学习路径 | 查看 AI 生成 / 管理员指派的学习路径 |
| 消息通知中心 | 指派通知、批阅完成通知、学习提醒通知（后续企微推送） |

## 三、管理端

> **导航菜单：** 数据概览、课程管理、Blocks 创建、考试管理、学员管理

### 3.1 数据概览

#### 3.1.1 整体培训统计

| 指标 | 说明 |
|------|------|
| 学员学习完成率 | 全员平均完成率 + 趋势 |
| 课程完成情况 | 已发布课程数 / 学员完成数 |
| 考试通过率 | 全员考试平均通过率 |

#### 3.1.2 筛选与看板

- 支持按部门、岗位筛选查看汇总数据
- 部门学习完成率图表（柱状图）
- 待处理事项汇总（待阅卷、待审核课程、Blocks 推送待确认、新员工待分配）
- 定位：基础看板，不做复杂 BI，满足基础管理查看

### 3.2 课程管理

> 课程按部门维度归类管理。

#### 3.2.1 列表筛选条件

- 课程名称（模糊搜索）
- 创建人
- 所属部门

#### 3.2.2 课程上传

点击"上传课程"弹出编辑框，填写字段：

| 字段 | 说明 |
|------|------|
| 课程名称 | 必填 |
| 课程分类 | 规章制度 / 企业文化 / 工作流程 / 行业知识 / 岗位知识 |
| 所属部门 | 共享课程 / 业务部 / 客服部 / 商务部 / 产品部 / 职能部 |
| 适用岗位 | 业务岗 / 客服岗 / 商务岗 / 产品岗 / 职能岗 |
| 类型 | 文档 / 表格 / PPT / PDF / 视频 |
| 难度 | 入门 / 进阶 / 高级 |
| 课程封面图 | 上传图片，未上传时按分类色彩展示 |
| 课程简介 | 文本描述 |
| 创建人 | 自动记录 / 手动填写 |

#### 3.2.3 标签体系

- 部门标签：共享课程、业务部、客服部、商务部、产品部、职能部门
- 难度标签：入门、进阶、高级

#### 3.2.4 课程列表与操作

- 简易排列展示已有课程，按基础信息分列
- 操作列：编辑、删除、查看预览

### 3.3 Blocks 创建（课程包 / 学习包）

> Blocks 按部门维度归类管理。

#### 3.3.1 列表筛选条件

- Blocks 名称
- 所属部门
- 创建人

#### 3.3.2 创建 Blocks

- 左侧可选内容库（分类展示）：课程、练习题、试卷
- 右侧已选内容（点击左侧添加）
- 操作：创建 Blocks（暂不推送）/ 清空重选

#### 3.3.3 创建逻辑

- 创建保存后 → 进入已创建 Blocks 列表
- **不会直接推送给学员**，需管理员手动指派才发送
- 可推送指定学员，也可批量推送

#### 3.3.4 Blocks 列表展示

- 部门 / 岗位标签视觉标识：圆形图标 + 关键字
  - 业务部→"业"、客服部→"客"、商务部→"商"、产品部→"产"、职能部→"职"、共享→"共"
- 每个 Blocks 展示：基本信息 + 以下操作按钮

| 操作 | 说明 |
|------|------|
| 推送学员 | 出现按部门 / 按指定学员推送选项 |
| 编辑 | 重新编辑已创建的 Blocks 内容 |
| 复制 | 复制一份 Blocks 副本 |
| 删除 | 删除该 Blocks |
| 指派设置 | 设置学习截止时间（超时发企微提醒，Phase 3） |

#### 3.3.5 企微能力预留

- 企微环境下，指派推送后企业微信推送消息 + 学习提醒

### 3.4 考试管理

#### 3.4.1 题库管理

**题目录入模式：**

| 模式 | 说明 |
|------|------|
| 单题编辑 | 新增题目，题型选择（单选 / 多选 / 判断 / 简答 / 主观题）+ 题干输入 + 答案输入 + 保存 |
| 批量上传 | 上传文档（Word / Excel / TXT）批量导入题目 |

**题库列表：** 查看编辑删除题目，标记适用岗位 / 分类

**题库分类（题库包）：** 管理员可创建题库包，归纳同一类题目，组卷时可从题库包选取

#### 3.4.2 试卷管理

**新建试卷字段：**

| 字段 | 说明 |
|------|------|
| 试卷名称 | 必填 |
| 适用人群 | 全司通用 / 业务岗 / 客服岗 / 商务岗 / 产品岗 / 职能岗 |
| 添加题目 | 从题库或题库包中勾选 |
| 及格分数 | 满分 100，设置及格线 |
| 考试时长 | 分钟 |
| 是否允许重考 | 开关 |
| 试卷副本 | 复制功能 |

**试卷列表操作：** 编辑、预览、复制副本、发布（草稿→已发布）、删除、指派下发给学员

**试卷状态：** 草稿 / 已发布（草稿状态下可点击发布）

#### 3.4.3 阅卷列表

- 学员提交试卷后，待阅卷试卷出现在列表，给管理员批阅提醒
- 支持 AI 辅助批改主观题（Skill 调用，减少人工阅卷）
- 管理员批阅主观题 → 批阅完成 → 学员端同步推送成绩通知
- 学员可查看成绩与阅卷详情

### 3.5 学员管理

#### 3.5.1 学员列表

| 字段 | 说明 |
|------|------|
| 姓名 | — |
| 入职时间 | — |
| 部门 | 业务部 / 客服部 / 商务部 / 产品部 / 职能部 |
| 岗位层级 | 新人期 / 成长期 / 专业期 / 资深期 |
| 账号权限状态 | 开通 / 关闭 |
| 已完成课程数 | — |
| 平均完成率 | — |

**批量操作：** 批量开启 / 关闭账号

**多条件筛选：** 姓名、部门、账号状态、完成率区间

#### 3.5.2 学员详情页

| 功能 | 说明 |
|------|------|
| 学习评价 | 管理员输入文字评价（有权限控制，可选择是否同步给学员） |

| 考试成绩 | 查看该学员的历史考试成绩 |
| 学习反馈 | 查看学员提交的反馈 |

#### 3.5.3 企微能力预留

## 四、非功能需求

| 类别 | 要求 |
|------|------|
| 兼容性 | Chrome / Edge / 企微内置浏览器；移动端适配（企微内嵌网页） |
| 性能 | 首屏加载 < 3s；页面切换无刷新（SPA 式交互） |
| 安全性 | 登录态校验（Phase 3 企微 OAuth）；管理端接口权限校验；敏感操作二次确认 |
| 数据隔离 | 学员仅可见自己数据；管理员可见全量数据 |
| 部署 | 静态托管（Vercel / Netlify），Phase 2 上线 |
| 技术栈 | 原生 HTML / CSS / JS（零依赖，无构建工具）；数据库 Supabase（Phase 4） |
| 可维护性 | data.js 独立数据层，Phase 4 换 Supabase API 只改此文件 |

## 五、原型对照差异表（Phase 1 已有 ↔ 需补充）

> 基于 `etblocks/` 工作区现有原型，标注每项需求的状态。

### 学员端差异

| 需求项 | 原型状态 | 差异说明 |
|--------|---------|----------|
| 工作台（首页） | ❌ 无 | 原型无独立首页，需新增工作台页面，AI 诊断放首页核心位 |
| 首页 4 块卡片 | ❌ 无 | 需新增已完成课程 / 待处理任务 / 我的学习路径 / 接下来要做 |
| AI 问题诊断位置 | ⚠️ 在侧栏 | 需从侧栏移至首页最显眼位置 |
| 课程播放页 | ❌ 无 | 原型无课程详情播放页，需新增（含视频倍速 / 全屏） |
| Blocks 在学习列表展示 | ❌ 无 | 学习列表仅展示单个课程，需增加 Blocks 卡片展示 |
| 待学通知 & 角标 | ⚠️ 部分 | 有待学列表但无通知提醒 & 数量角标 |
| 任务到期时间 & 超时状态 | ❌ 无 | 需增加到期时间展示 + 超时红色标签 |
| 错题本 | ❌ 无 | 课后训练仅 3 标签（练习 / 考试 / 指派），需新增错题本标签 |
| 练习题答题交互 | ❌ 无 | 原型仅展示表格列表，需新增答题框 + 完成后展示参考答案 |
| 试卷答题页 | ❌ 无 | 原型仅展示试卷列表，需新增答题页面 + 查看阅卷结果 |
| 个人中心 | ❌ 无 | 完全新增页面（基础信息 / 学习记录 / 学习路径 / 消息通知） |

### 管理端差异

| 需求项 | 原型状态 | 差异说明 |
|--------|---------|----------|
| 数据概览按部门 / 岗位筛选 | ❌ 无 | 有图表但无筛选下拉 |
| 课程管理筛选（创建人） | ⚠️ 部分 | 有搜索和分类筛选，缺创建人筛选 |
| 课程查看预览 | ❌ 无 | 操作列有编辑但无预览功能 |
| Blocks 推送学员按钮 | ❌ 无 | 有创建列表但无推送 / 指派操作 |
| Blocks 编辑 / 复制 / 删除 | ❌ 无 | 列表仅展示，无操作按钮 |
| Blocks 指派截止时间 | ❌ 无 | 需新增截止时间设置 |
